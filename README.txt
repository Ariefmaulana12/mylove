CARA MENGGUNAKAN FOLDER GALERY
================================

Folder ini digunakan untuk menyimpan foto-foto kenangan yang akan ditampilkan di website surprise.

LANGKAH-LANGKAH:
1. Upload atau copy foto-foto Anda ke folder ini
2. Rename foto sesuai dengan nama berikut:
   - foto1.jpg (atau .png/.jpeg)
   - foto2.jpg
   - foto3.jpg
   - foto4.jpg
   - foto5.jpg
   - foto6.jpg

TIPS:
- Gunakan foto dengan kualitas baik untuk hasil terbaik
- Format yang didukung: .jpg, .jpeg, .png
- Jika foto tidak ditemukan, akan muncul icon bunga sebagai placeholder
- Foto akan otomatis disesuaikan ukurannya (250px tinggi)

Selamat mencoba! ❤️
